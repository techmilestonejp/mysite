OracleDBのインストール手順

OracleLinux上のOracleDBインストール手順

OracleLinux上でOracleDBをインストールする(構築する)手順としては、以下の種別があります。

  • OracleLinuxのインストール手順の種別/23aiFree以後
    • VirtualBoxで仮想サーバを構築して、「23ai Free」(RPMインストール)でインストールを行う
    • VirtualBoxのovaファイル(「23ai Free」導入済)を利用して、仮想サーバを構築する
  • OracleLinuxのインストール手順の種別/Docker環境(23aiFree)
    • Docker環境上でOracle Databaseインストール
  • OracleLinuxのインストール手順の種別/従来型
    • VirtualBoxで対応OSが導入された仮想サーバ(VMサーバ)を構築して、Oracleメディアのインストールを行う
  • OracleLinuxのインストール手順の種別/OracleLinux構築のみ
    1. Vagrantを使用して、VagrantBoxesによるインストールを行う

従来型インストールの廃止について

従来型のインストール手順は23ai移行からは廃止されています。
