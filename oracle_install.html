OracleDBのインストール手順

OracleLinuxのインストール

OracleLinux上でOracleDBを構築する手順として以下のような種別があります。

  • OracleLinuxのインストール手順の種別
    1. VirtualBoxで仮想サーバを構築して、メディアインストールを行う
    2. VirtualBoxのovaファイルを利用して、仮想サーバを構築する
    3. VirtualBoxで仮想サーバを構築して、「23ai Free」でインストールを行う
    4. Vagrantを使用して、VagrantBoxesによるインストールを行う
