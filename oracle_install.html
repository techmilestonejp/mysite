OracleDBのインストール手順

OracleLinux上のOracleDBインストール手順

OracleLinux上でOracleDBをインストールする(構築する)手順としては、以下の種別があります。

  • OracleLinuxのインストール手順の種別
    1. VirtualBoxで対応OSが導入された仮想サーバ(VMサーバ)を構築して、Oracleメディアのインストールを行う
    2. VirtualBoxのovaファイルを利用して、仮想サーバを構築する
    3. VirtualBoxで仮想サーバを構築して、「23ai Free」(RPMインストール)でインストールを行う
    4. (OracleLinux構築のみ)Vagrantを使用して、VagrantBoxesによるインストールを行う
