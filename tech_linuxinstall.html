Linux Mint/後設定

Linux Mint/後設定

(ホームディレクトリを英表記に変更)

LANG=C xdg-user-dirs-gtk-update

(SSHインストール)

sudo apt install openssh-server
systemctl status ssh

(sambaインストール)

sudo apt install -y samba

(sambaユーザー作成)

sudo smbpasswd -a xxxxxx(OSユーザ名)

(smb.conf設定)
既存のsmb.confの最終行に以下を追加します。
以下設定でホームディレクトリへのファイル操作が可能となります。

[homes]
read only = no
writable = yes
create mask = 0777
directory mask = 0777

(samba再起動)

sudo systemctl restart smbd.service
